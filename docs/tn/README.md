# Technical Notes (TN)

Numbered timeline documents — proposals, specs, plans, explorations, research. The working surface where ideas develop. Ratified decisions are promoted to ADRs/CDRs under [`docs/decisions/`](../decisions/).

See [TN-2026-001](TN-2026-001-technical-notes-and-doc-structure.md) for the system definition: numbering, front matter schema, status semantics, workflow, and the **TN style rule** (compact, bulleted, no long prose).
